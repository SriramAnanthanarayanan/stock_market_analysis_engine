4. Feature 1 — Marubozu candlestick detection

Add a separate Candlestick Patterns category.

First implementation:

- Bullish Marubozu.
- Bearish Marubozu.

4.1 Initial numerical rules

These are configurable starting defaults:

Parameter| Initial value
Body / total candle range| >= 90%
Upper wick / total range| <= 5%
Lower wick / total range| <= 5%
Minimum candle range| > 0
Volume lookback| 20 bars

Definitions:

candle_range = high - low
body = abs(close - open)

upper_wick = high - max(open, close)
lower_wick = min(open, close) - low

body_ratio = body / candle_range
upper_wick_ratio = upper_wick / candle_range
lower_wick_ratio = lower_wick / candle_range

Bullish Marubozu:

close > open
body_ratio >= 0.90
upper_wick_ratio <= 0.05
lower_wick_ratio <= 0.05

Bearish Marubozu:

close < open
body_ratio >= 0.90
upper_wick_ratio <= 0.05
lower_wick_ratio <= 0.05

Exclude zero-range candles and invalid OHLC records.

The thresholds must be configurable.

4.2 Additional metrics

For every detected Marubozu, calculate:

- Body percentage.
- Upper wick percentage.
- Lower wick percentage.
- Total candle range.
- Range / ATR(14).
- Volume.
- Volume ratio against previous 20 completed candles.
- Candle timestamp.
- Timeframe.

Do not make volume a mandatory Marubozu validity condition.

Volume should be shown as supporting information.

4.3 UI

Display a distinct marker on the Marubozu candle.

Show the detected candle's metrics in the chart details panel.

Allow filtering by:

- Bullish Marubozu.
- Bearish Marubozu.
- Timeframe.
- Minimum candle range in ATR.
- Minimum relative volume.

Do not call every large-bodied candle a Marubozu. Follow the configured numerical rules.

5. Feature 2 — 10-day high breakout and 10-day low breakdown

Add a new Breakout Scanner category.

Initially implement:

- 10-day high breakout.
- 10-day low breakdown.

Make the lookback configurable so 20-day and 50-day levels can be added without redesigning the module.

5.1 Numerical definition

Use the previous ten completed daily candles. Exclude the current daily candle from the reference window.

previous_10_day_high = max(previous_10_daily_highs)
previous_10_day_low = min(previous_10_daily_lows)

Bullish breakout:

close > previous_10_day_high + break_buffer

Bearish breakdown:

close < previous_10_day_low - break_buffer

Initial break buffer:

"0.1 × ATR(14)"

The reference period must contain ten completed daily candles, not ten calendar days.

A completed daily candle is required for a confirmed breakout.

Use these configurable confirmation modes:

- One completed close beyond the level.
- Two consecutive completed closes beyond the level.

Default: one completed close. Display whether confirmation is one-close or two-close.

5.2 Additional breakout metrics

Calculate:

- Previous 10-day high.
- Previous 10-day low.
- Distance from reference level.
- Breakout percentage.
- Breakout candle range / ATR.
- Volume ratio relative to previous 20 daily candles.
- Previous resistance/support level.
- Confirmation status.
- Breakout date and timestamp.

Volume is a supporting confirmation metric, not a mandatory condition unless enabled by the user.

5.3 Timeframe handling

The 10-day breakout must always use daily candles.

When the user views a 1H or 4H chart:

- Overlay the current daily 10-day high and low levels.
- Clearly label the levels as daily-derived.
- Do not accidentally calculate a ten-hour or ten-bar breakout.
- Show the latest completed daily reference candle date.

When the daily breakout is detected, mark the corresponding breakout on the daily chart.

5.4 Breakout Scanner UI
